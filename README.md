# Dangan (弾丸)

(logo here)

Three *evil* princesses have taken over the kingdom. Only you can stop them. Dodge their attacks, and defeat them all to restore peace in the kingdom.

Welcome to **Dangan**! In this challenging topdown bullet-hell game, you must defeat all three levels to win.

## Installation

This project uses Python 2.6.1

> pip install -r requirements.txt

Install all required libraries, and make sure the files are located one
