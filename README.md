# Dangan (弾丸)

Welcome to **Dangan**! In this challenging topdown bullet-hell game, you must defeat all ~~three~~ two (evil) princesses to win. Dodge their attacks, fire shots back, and achieve the highest ranks on all levels!

<img width="450" height="316" alt="Dangan Gameplay" src="https://github.com/user-attachments/assets/de54f949-3100-41e1-bb47-6f20520e7da5" />

## Controls

`↑←↓→ or WASD`: Movement and Navigate  
`SPACE`: Shoot and Select  
`ESC`: Exit Level/Screen

## Installation

This project uses Python 2.6.1

Install required dependencies using the following command.
```
pip install -r requirements.txt
```

Install all required libraries, and make sure the files are located one
